# Перекуп

Браузерный прототип игры. Откройте `index.html` либо запустите `python3 -m http.server 8000` в этой папке.

Комната, двор, парк, гаражи, ТЦ, ПВЗ и карта четырёх районов. Календарь, время, погода и сезонные кадры. Нижняя часть сцены открывает карту. На карте нажмите название нужного места.

Весь интерфейс и логика находятся в `index.html`, изображения — в `assets/`.
